# Timing objection

> MOCK DATA. Written for the Caddy Lab prototype to stand in for a real recruiting best-practice corpus.

## What's really going on

'Now's not the right time' is usually a polite no or a real constraint, and you have to work out which without being pushy. Real constraints have dates attached: a bonus in March, a vest in June, a wedding in August. Polite nos are vague. If there's a date, work back from it and see if the client can flex. If it's vague, the objection is something else and timing is the cover story.

## Dig deeper

1. What specifically makes now tricky? Is there a date you're waiting for?
2. If that date had already passed, would you be moving on this?
3. What would need to happen between now and then for you to be ready?
4. Would it help if the start date was set around that?

## Watch for

No date usually means no interest. Gently ask what would make it the right time, then listen for the real objection.
